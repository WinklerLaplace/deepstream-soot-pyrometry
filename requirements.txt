# ==========================================================
# 1. PYTHON
# ==========================================================
#
# Python 3.10.x es requerido.
#
# En Jetson (Ubuntu):
#   sudo apt install python3.10 python3.10-venv python3-pip
#
# En Windows (x86):
#   Descargar e instalar manualmente:
#   https://www.python.org/ftp/python/3.10.11/python-3.10.11-amd64.exe
#
# Verificar:
#   python --version
#

# ==========================================================
# 2. NVIDIA STACK (CUDA / cuDNN / TensorRT)
# ==========================================================
#
# --------------------------
# CASO A: Jetson
# --------------------------
#
# No instalar CUDA, cuDNN ni TensorRT manualmente.
# Todo el stack viene incluido con JetPack.
#
# JetPack validado:
#   JetPack 36.4.7 (R36)
#
# Versiones resultantes:
#   CUDA:        12.6
#   cuDNN:        9.3.0
#   TensorRT:    10.3.0
#
# Instalación típica:
#   - Flashear Jetson con SDK Manager
#   - O instalar vía APT si el sistema ya está flasheado
#
# Verificación:
#   nvcc --version
#   python -c "import tensorrt as trt; print(trt.__version__)"
#
# --------------------------
# CASO B: x86 / Windows / Linux genérico
# --------------------------
#
# En este caso, el stack NVIDIA debe instalarse MANUALMENTE
# y respetando la matriz de compatibilidad.
#
# 1) CUDA Toolkit:
#    https://developer.nvidia.com/cuda-13-0-0-download-archive
#
# 2) cuDNN:
#    https://developer.nvidia.com/rdp/cudnn-archive
#
# 3) TensorRT:
#    https://developer.nvidia.com/tensorrt/download/10x
#
# 4) Ver compatibilidad:
#    https://docs.nvidia.com/deeplearning/tensorrt/latest/getting-started/support-matrix.html
#
# NOTA:
# - CUDA, cuDNN y TensorRT deben coincidir entre sí
# - PyTorch debe ser compatible con esa versión de CUDA
#
